Section 02

Add Your Videos (Cloudinary)

Videos must be hosted online so anyone with your portfolio link can watch them. Cloudinary is free and works best.

1
Create a free Cloudinary account Go to cloudinary.com → Sign up free. No credit card needed.
2
Upload your video files Click Upload in the dashboard → select your MP4 files → wait for upload to finish.
3
Copy the video URL Click the uploaded video → click the link icon → copy the URL. It looks like:
https://res.cloudinary.com/your-name/video/upload/v123/video.mp4
4
Paste URLs into the project Open src/data/projects.js and replace each placeholder with your real URL.
React version: Edit only src/data/projects.js to update all video URLs and project details. No other file needs to change.

projects.js — What to edit

const projects = [
  {
    id: 1,
    title: 'Your Project Title',          // ← change this
    description: 'Your description',      // ← change this
    category: 'branding',                 // ← branding / explainer / social / 3d
    tools: ['After Effects', 'Cinema 4D'],// ← your tools
    videoUrl: 'https://res.cloudinary.com/YOUR_ACCOUNT/video/upload/your-video.mp4',
  },
  // ... repeat for each project
]
Section 03

Run Locally

HTML Version — No installation needed

1
Open the portfolio folder Navigate to portfolio/ on your computer.
2
Double-click index.html It opens in your browser. That's it — no server needed.

React Version — Requires Node.js

Step 1 — Install Node.js (only once)

# On Ubuntu / Linux
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Verify install
node --version    # should show v20.x.x
npm --version     # should show 10.x.x

Step 2 — Install dependencies (only once)

cd /home/pooja/Metaveo/portfolio-react
npm install

Step 3 — Start the dev server

npm run dev
After running npm run dev, open your browser and go to http://localhost:5173 — your portfolio is running locally. Changes you make to any file update instantly in the browser.
Section 04

Share with Anyone — Deploy Online

Deploying puts your portfolio on the internet so anyone can open it with one link. Both options below are completely free.

Option A — Netlify (Easiest, recommended)

For the HTML version (no build needed):

1
Go to netlify.com/drop Open app.netlify.com/drop in your browser.
2
Drag the portfolio folder Drag the entire portfolio/ folder into the Netlify page.
3
Get your link Netlify gives you a URL like https://bright-sun-abc123.netlify.app — share it!

For the React version (build first):

# Build the project (creates a dist/ folder)
cd /home/pooja/Metaveo/portfolio-react
npm run build

# Then drag the dist/ folder to netlify.com/drop

Option B — Vercel

# Install Vercel CLI
npm install -g vercel

# Deploy from project folder
cd /home/pooja/Metaveo/portfolio-react
vercel

# Follow the prompts — you'll get a live URL
Result: Your friend receives one link, e.g. https://abc-portfolio.netlify.app. They click it. The portfolio opens in their browser. They see your work, your videos play, everything works. No files to send, no installation for them.
